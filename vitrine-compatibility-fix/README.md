# VitrineCompatibilityFix 1.0

Standalone Spotify companion dylib for Vitrine.

It suppresses only Vitrine's EeveeSpotify and unsupported-Spotify-version warnings in the Vitrine UI. It keeps Vitrine's real EeveeSpotify detection and lyrics safety logic intact, keeps the real Spotify version intact, and preserves unrelated Vitrine environment warnings.

This folder is isolated for validation and is not yet wired into the v5 Injector core/addons.
