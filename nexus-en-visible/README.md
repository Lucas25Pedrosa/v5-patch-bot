# Nexus English — iQFace Icon Visible

Separate Nexus 1.0.2 English variant for iQFace 1.1.

This variant keeps the original iQFace settings launcher/icon visible. It is intentionally isolated from `nexus-en` and has its own workflow and build helpers.

It keeps the validated Nexus 1.0.2 modules, including the community/group avatar no-flash fix, but does not compile the launcher-hiding fallback (`HideButton11.m`) and does not install the Enhancer navigation-item hiding hooks.
