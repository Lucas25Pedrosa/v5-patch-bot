# iQFaceCache 0.2.0

- Automatic cache cleaning: Never / Daily / Weekly / Monthly.
- Production intervals: 24 hours / 7 days / 30 days.
- Changing the frequency restarts the countdown.
- Selecting Never clears the saved automatic-cleaning timestamp.
- Automatic cleaning is silent in the final release.
- Manual cleaning keeps the cache-cleaned confirmation.
- Cleaning remains limited to the two validated Facebook cache directories.
